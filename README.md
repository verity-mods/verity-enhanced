We believe in full compatibility. Inside the downloaded ZIP archive, you will find mod files for **every single official Minecraft release** from 1.18 up to 1.21.11.

**🛠️ Step-by-Step Guide:**

1. Click the **Download** button above to get the `verity_enhanced_v2.0.0.zip` archive.
2. Extract the ZIP file.
3. Inside, you will see folders named by major version (`1.18`, `1.19`, `1.20`, `1.21`). Open the folder that matches your game (for example, `1.20`).
4. Find the exact `.jar` file that matches your current game version (e.g., `verity-enhanced-1.20.4.jar`).
5. **Move ONLY that specific `.jar` file** into your `%appdata%\.minecraft\mods` folder.

## ❓ FAQ

**Is this an official update?**
No, this is an unofficial community remaster. We are huge fans of the original mod and wanted to expand upon it. All credit for the original concept goes to the original creator.

**Is this a virus?**
No, it's a standard Java modification. Because we use custom AI libraries to improve Verity's behavior, some antiviruses may flag it as a false positive. You may need to add an exception in Windows Defender.

**Why does my game crash on startup?**
Make sure you have the correct Forge version installed for your Minecraft version. Also, ensure you only placed *one* version of the mod in your `mods` folder (e.g., don't put both 1.19 and 1.20 jars in there at the same time).

This is a fan-made project. It is not affiliated with the original developer or Mojang. Use at your own risk. Always back up your worlds before installing new mods.
