### 🛠️ How to install
1. Ensure you have **Minecraft Forge** installed (versions 1.18 to 1.20.4 are supported).
2. Download the `.jar` file using the button above.
3. Put the `.jar` file into your `.minecraft/mods` folder.
4. Launch the game. (Note: If upgrading from the original mod, please start a fresh world to avoid script conflicts).

## ❓ FAQ

**Is this an official update?**
No, this is an unofficial community remaster. We are huge fans of the original mod and wanted to expand upon it. All credit for the original concept goes to the original creator.

**Is this a virus?**
No, it's a standard Java modification. Antiviruses sometimes flag mods that heavily modify game files, so you may need to add an exception.

**Why does my game crash on startup?**
Make sure you have the correct Forge version installed for your Minecraft version. Also, ensure you don't have the original Verity mod installed alongside this one, as they will conflict.
